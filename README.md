# MOMENT — 나에게 집중하는 시간

수면·마음챙김 명상 웹앱. `moment_meditation_design.html` 디자인 시스템(세이지 그린, 흰 카드, 하단 4탭)을 기준으로 만들었습니다.

## 화면
- **홈**: 오늘의 추천 명상(날짜마다 바뀜), 바로 시작
- **탐색**: 01 꽃과 나비 · 02 고요한 산책길 · 03 물결과 호흡
- **명상**: 실제 자연 녹음 재생, 시간 설정(5분~1시간·끄지 않기), 배경음 4종, 볼륨, 끝날 때 15초 동안 소리 줄이기
- **호흡**: 4초 들숨 · 6초 날숨, 1/3/5분
- **MY**: 이 기기에 저장되는 실제 기록(누적 시간, 명상 일수, 연속 일수, 이번 주 그래프), 화면 켜두기·잠들기 화면 설정
